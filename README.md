# tg-archive

Инструмент для архивации публичных Telegram-групп с поддержкой тем (топиков). Синхронизирует сообщения, медиафайлы и информацию о пользователях в локальную базу данных SQLite. Позволяет выполнять инкрементальную синхронизацию в "новом" (`forward`) и "старом" (`backward`) направлениях.

## Возможности

*   **Архивация сообщений:** Сохранение текста, времени отправки, ID, информации об отправителе.
*   **Поддержка тем (топиков):** Автоматическое обнаружение и классификация сообщений по темам.
*   **Сохранение медиа:** Скачивание и кеширование фото, видео, документов с проверкой на дубликаты.
*   **Информация о пользователях:** Сохранение и обновление данных о пользователях (имя, юзернейм).
*   **Инкрементальная синхронизация:** Возможность синхронизировать только новые сообщения (`forward`) или до определённого момента (`backward`).
*   **Фильтрация по темам:** Возможность синхронизировать только указанные темы.
*   **Хранение в SQLite:** Надёжное и локальное хранение данных.

#### Этап 0: конфигурирование
Настройте конфигурацию:
*   Скопируйте `config.yaml.example` в `config.yaml`.
*   Заполните `config.yaml` вашими `api_id`, `api_hash`, `session_name` и `group_id` (ID вашей Telegram-группы). Инструкции по получению `api_id` и `api_hash` можно найти на [официальном сайте Telegram](https://core.telegram.org/api/obtaining_api_id).

#### Этап 1: Инициализация  

Подготовка базы данных и директорий для хранения медиа и аватаров.
```bash
python tg_archive.py init --config config.yaml
```  
- Создание БД  
- Создание структуры каталогов 

#### Этап 2: Синхронизация  
```bash
python tg_archive.py sync --config config.yaml [опции]
```  
1. --sync-direction {forward,backward}: Направление синхронизации.
    forward (по умолчанию): Искать новые сообщения, начиная с last_message_id (эффективно для ежедневного обновления).
    backward: Искать старые сообщения, начиная с last_message_id или с самого начала (полезно для первоначальной полной синхронизации).
2. --topics <ID_1> [ID_2] ...: Синхронизировать только указанные темы (по ID). Если не указано, синхронизируются все темы.
3. --verbose: Включить подробный лог.

Примеры:
* Синхронизация новых сообщений во всех темах: python tg_archive.py sync --config config.yaml
* Синхронизация новых сообщений только в теме 1143: python tg_archive.py sync --config config.yaml --topics 1143
* Синхронизация старых сообщений в теме 1143 с подробным логом: python tg_archive.py sync --config config.yaml --sync-direction backward --topics 1143 --verbose

#### Этап 3: Генерация сайта  
```bash
python tg_archive.py generate --config config.yaml
```  
- Рендеринг HTML-страниц  
- Копирование медиаресурсов в output
