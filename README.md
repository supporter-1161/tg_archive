### Техническое задание: Архиватор Telegram-групп с поддержкой тем (tg-archive)

---

**1. Общее описание**  
Разработать инструмент для архивации публичных Telegram-групп с поддержкой тем (топиков). Система должна:  
- Автоматически синхронизировать сообщения через Telegram API  
- Сохранять данные в SQLite  
- Генерировать статический веб-архив с навигацией по темам и датам  

---

**2. Технические требования**  

#### 2.1. Сбор данных (Telegram API)  
- **Технология**: Python 3.10+ с библиотекой Telethon. Использовать файл сессии для каждого экземпляра клиента. При создании TelegramClient использовать уникальное имя сессии, а также реалистичные параметры app_version, device_model и system_version, чтобы снизить вероятность срабатывания механизмов безопасности Telegram. 
- **Поддержка тем**:  
  - Автоматическое обнаружение и классификация сообщений по темам  
  - Обработка параметров `message.is_topic_message` и `message.reply_to.forum_topic`  
- **Инкрементальная синхронизация**:  
  - Хранение `last_message_id` для каждой темы в SQLite  
  - Пакетная загрузка сообщений с фильтрацией по `offset_id`  
- **Обработка контента**:  
  - Скачивание медиафайлов (фото, видео, документы) с кешированием  
  - Конвертация стикеров в эмодзи  
  - Парсинг опросов с сохранением структуры голосов  
- **Управление пользователями**:  
  - Локальное сохранение аватаров (обновление при изменении)  
  - Кеширование данных пользователей
