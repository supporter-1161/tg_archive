Техническое задание: Архиватор Telegram-групп с поддержкой тем (tg-archive)

---

**1. Общее описание**  
Разработать инструмент для архивации публичных Telegram-групп с поддержкой тем (топиков). Система должна:  
- Автоматически синхронизировать сообщения через Telegram API  
- Сохранять данные в SQLite  
- Генерировать статический веб-архив с навигацией по темам и датам  

---

**2. Технические требования**  

#### 2.1. Сбор данных (Telegram API)  
- **Технология**: Python 3.10+ с библиотекой Telethon. Использовать файл сессии для каждого экземпляра клиента. При создании TelegramClient использовать уникальное имя сессии, а также реалистичные параметры app_version, device_model и system_version, чтобы снизить вероятность срабатывания механизмов безопасности Telegram. 
- **Поддержка тем**:  
  - Автоматическое обнаружение и классификация сообщений по темам  
  - Обработка параметров `message.is_topic_message` и `message.reply_to.forum_topic`  
- **Инкрементальная синхронизация**:  
  - Хранение `last_message_id` для каждой темы в SQLite  
  - Пакетная загрузка сообщений с фильтрацией по `offset_id`  
- **Обработка контента**:  
  - Скачивание медиафайлов (фото, видео, документы) с кешированием  
  - Конвертация стикеров в эмодзи  
  - Парсинг опросов с сохранением структуры голосов  
- **Управление пользователями**:  
  - Локальное сохранение аватаров (обновление при изменении)  
  - Кеширование данных пользователей  


Процесс работы**  

#### Этап 1: Инициализация  
```bash
python tg_archive.py init --config config.yaml
```  
- Создание БД  
- Первичная синхронизация тем  

#### Этап 2: Синхронизация  
```bash
python tg_archive.py sync --config config.yaml
```  
1. Получение списка тем  
2. Для каждой темы:  
   - Загрузка новых сообщений (начиная с last_message_id)  
   - Возмножность указать загрузку только определенной темы - опция --topics <номер топика>
   - Возможность расширенного вывода отладочной информамции - опция --verbose
   - Скачивание медиа и аватаров  
   - Обновление last_message_id  
3. Обработка глобальных сообщений (вне тем)  

#### Этап 3: Генерация сайта  
```bash
python tg_archive.py generate --config config.yaml
```  
- Рендеринг HTML-страниц  
- Копирование медиаресурсов в output  


**Требования к интерфейсу**  
* **Главная страница:**
	* Шапка сайта с названием, датой обновления и счетчиком количества сообщений 
	* Возможность включения бегущей строки с объявлениями от администрации.
	* Боковое меню со списком тем
	* темная и светлая темы интерфейса
	* Основное пространство выделено под описание.
	* подвал с датой обновления, счетчиком количества сообщений 
- **Страница темы с сообщениями**:  
	- Шапка сайта с названием, датой обновления и счетчиком количества сообщений 
	* Возможность включения бегущей строки с объявлениями от администрации.
	- Иконка и название темы  
	- Хронологическая навигация
	- фиксировано отображение количества сообщений на странице - должно быть настраиваемо
